# What if plants screamed when thirsty? (Reel)

- `plants-scream-v2.mp4`: the finished Reel with the upbeat short-form narrator (take two). `plants-scream.mp4` is take one with the deadpan narrator, 1080x1920, 30 fps, 36.4 s, with sound.
- `cover.png`: suggested cover frame.
- `POSTS.md`: captions.
- `film.html`: the film itself, every frame drawn in code. Preview with `node serve.mjs` or render stills with `node frames.mjs 1 0.5,5,10`.
- `audio/`: narration and scream recordings (ElevenLabs), the music score (`bed.mjs`) and the mix recipe (`mix.py`).

Re-render the picture: `W=1080 H=1920 node export.mjs 30 work/picture.mp4`
